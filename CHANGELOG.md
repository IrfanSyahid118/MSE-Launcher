# Changelog

All notable changes to MSE Launcher are documented here. The current version is `v1.2.1-beta`.

## [1.2.1-beta] — 2026-11-17

- Custom Tauri GUI installer and uninstaller (`5fc1eac`).
- Critical security, launch, modpack, and UI bug fixes (`3ec1207`).

## [1.2.0-beta] — 2026-11-15

- Deep debug fixes across launcher crates, IPC, and UI (`38ba850`).
- Audit and clean redundant code comments (`db37df7`).

## [1.0.0-beta] — 2026-11-14

- Initial beta release with Vanilla & mod loader management (Fabric, Quilt, NeoForge, Forge), Modrinth & CurseForge browser, Microsoft/offline accounts, 3D skin viewer, isolated instances, Java & RAM manager, server list manager, screenshot gallery, Discord Rich Presence, in-app SHA-256 verified auto-updater (Portable vs Installer), and compile-time CurseForge proxy support (`f8054dd`).
